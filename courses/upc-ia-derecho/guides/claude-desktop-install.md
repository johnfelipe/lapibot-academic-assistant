# Guía — Instalación de Claude Desktop

Guía para descargar, instalar y registrarte en Claude Desktop, necesaria para las prácticas del curso de la UPC.

## 1. Descarga
- Ingresa a https://claude.ai/download
- Elige la versión según tu sistema operativo (Windows o macOS).

## 2. Instalación
- **Windows:** ejecuta el archivo `.exe` descargado y sigue el asistente.
- **macOS:** abre el `.dmg` y arrastra Claude a la carpeta Aplicaciones.

## 3. Registro / inicio de sesión
- Abre la aplicación.
- Inicia sesión con tu correo (puedes usar Google) y verifica el código que llega a tu bandeja.

## 4. Verificación
- Escribe un mensaje de prueba, por ejemplo: "Hola, ¿estás listo para el curso de la UPC?"
- Si responde, la instalación fue correcta.

## 5. Recomendaciones para el curso
- Mantén la app actualizada.
- No compartas información confidencial de clientes reales en las prácticas.
- Si tienes problemas de instalación, escríbele al asistente del curso o al docente.
