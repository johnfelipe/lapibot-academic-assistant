# שיעור 2: Prompt Engineering — לכתוב הוראות ברורות

## סיכום
איך לכתוב פרומפטים אפקטיביים ל-LLMs. טכניקות לקבלת פלט עקבי ואיכותי.

## נושאים מרכזיים
- אנטומיה של פרומפט טוב: תפקיד, הקשר, משימה, מגבלות
- דוגמאות (Few-shot)
- חשיבה שלב אחרי שלב (Chain-of-thought)
- System prompt מול User prompt
- טעויות נפוצות ואיך להימנע מהן

## תובנות מרכזיות
- בהירות מנצחת חוכמה — הוראות מפורשות עדיפות על ניסוח מתוחכם
- הראה, אל תספר — דוגמאות חזקות יותר מתיאורים
- עבוד על פרומפטים כמו שעובדים על קוד — באיטרציות
